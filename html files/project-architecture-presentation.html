PROCESSING PIPELINE04
04 / Algorithms

How an answer becomes a score

Transparent heuristics make the local fallback inspectable and testable.

05
01

Weighted response score

Four independent signals are combined into a bounded 0-100 score. The question weight can amplify the result for important questions, with a final cap at 100.

Implemented scoring model
overall =
(relevance x .25)
+ (accuracy x .30)
+ (confidence x .20)
+ (keyword match x .25)
K

Keyword coverage

Lowercase answer text is checked for each expected keyword. Score = matched keywords / expected keywords x 100.

R

Question relevance

Uses shared answer/question words longer than three characters, then adds a length bonus for a substantive 30-200 word answer.

S

Skill presence

Six categories scan curated keyword sets: communication, problem solving, teamwork, leadership, technical, adaptability.

C

Confidence heuristic

Starts at 50, adjusts for positive and negative phrases, and considers response length. Result is clamped to 0-100.
